> 高性能网络编程提升系统吞吐量。

## IO模型

| 模型 | 说明 |
|------|------|
| **阻塞IO** | 同步等待 |
| **非阻塞IO** | 轮询检查 |
| **IO复用** | select/epoll |
| **异步IO** | 通知机制 |

## 线程池

```python
from concurrent.futures import ThreadPoolExecutor

pool = ThreadPoolExecutor(max_workers=10)

def task(n):
    return n * 2

pool.submit(task, 10)
```

## 小结

- **IO复用**：epoll/select
- **线程池**：复用线程
