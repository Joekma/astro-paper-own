> 代理服务器转发客户端请求。

## 正向代理

| 特点 | 说明 |
|------|------|
| **客户端代理** | 客户端感知代理存在 |
| **访问受限资源** | 突破限制 |
| **缓存加速** | 缓存常用资源 |

## 反向代理

| 特点 | 说明 |
|------|------|
| **服务端代理** | 客户端无感知 |
| **负载均衡** | 分发请求 |
| **安全防护** | 隐藏真实服务器 |

## Nginx 配置

```nginx
server {
    listen 80
    server_name example.com
    location / {
        proxy_pass http://backend
    }
}
```

## 小结

- **正向代理**：客户端代理
- **反向代理**：服务端代理
- **Nginx**：常用反向代理服务器
