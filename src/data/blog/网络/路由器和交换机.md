> 路由器和交换机是网络基础设备。

## 交换机

| 层级 | 说明 |
|------|------|
| **工作层** | 数据链路层 |
| **功能** | 帧转发 |
| **MAC 表 | 地址学习 |

## 路由器

| 层级 | 说明 |
|------|------|
| **工作层** | 网络层 |
| **功能** | 路由转发 |
| **路由表** | 路径选择 |

## 区别

| 设备 | 工作层 | 转发依据 |
|------|--------|---------|
| 交换机 | 数据链路层 | MAC 地址 |
| 路由器 | 网络层 | IP 地址 |

## 小结

- **交换机**：局域网设备
- **路由器**：网络互联
