## 概述

路由器和交换机是网络中两种最基础的设备，虽然外观相似，但功能和工作原理有本质区别。

## 交换机

### 工作原理

交换机工作在**数据链路层**（第二层），基于 MAC 地址转发数据：

```
┌────────────────────────────────────────────┐
│              Switch                        │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │ Port 1  │  │ Port 2  │  │ Port 3  │ │
│  │MAC: A    │  │MAC: B    │  │MAC: C   │ │
│  └──────────┘  └──────────┘  └──────────┘ │
│                                          │
│              MAC 地址表                    │
│  ┌─────────┬────────────┐                │
│  │ MAC    │ Port       │                │
│  ├─────────┼────────────┤                │
│  │ A       │ 1          │                │
│  │ B       │ 2          │                │
│  │ C       │ 3          │                │
│  └─────────┴────────────┘                │
└────────────────────────────────────────────┘
```

### MAC 地址学习

```python
# 交换机 MAC 地址表工作原理

class Switch:
    def __init__(self):
        self.mac_table = {}

    def learn(self, mac, port):
        self.mac_table[mac] = port

    def forward(self, frame):
        dst_mac = frame.destination

        if dst_mac in self.mac_table:
            port = self.mac_table[dst_mac]
            self.send_to_port(frame, port)
        else:
            self.flood(frame)  # 未知单播泛洪

        self.learn(frame.source_mac, frame.source_port)
```

### 交换机特点

| 特性 | 说明 |
|------|------|
| **工作层** | 数据链路层（L2） |
| **转发依据** | MAC 地址 |
| **广播域** | 交换机所有端口在同一广播域 |
| **冲突域** | 每个端口独立冲突域 |
| **延迟** | 低延迟（硬件转发） |
| **使用场景** | 连接同一网段的设备 |

## 路由器

### 工作原理

路由器工作在**网络层**（第三层），基于 IP 地址转发数据：

```
┌────────────────────────────────────────────┐
│              Router                        │
│  ┌──────────┐  ┌──────────┐             │
│  │ Eth0     │  │ Eth1     │             │
│  │ 192.168.1│  │ 10.0.0.1 │             │
│  └──────────┘  └──────────┘             │
│                                          │
│              路由表                       │
│  ┌───────────┬────────────────┐          │
│  │ Destination│ Gateway      │          │
│  ├───────────┼────────────────┤          │
│  │ 192.168.1.0│ 直连         │          │
│  │ 10.0.0.0   │ 直连         │          │
│  │ 0.0.0.0    │ 10.0.0.1    │          │
│  └───────────┴────────────────┘          │
└────────────────────────────────────────────┘
```

### 路由决策

```python
# 路由器路由决策过程

class Router:
    def __init__(self):
        self.routing_table = []

    def route(self, packet):
        dst_ip = packet.destination_ip

        longest_match = None

        for entry in self.routing_table:
            if self.match(entry.network, entry.mask, dst_ip):
                if not longest_match or entry.prefix_len > longest_match.prefix_len:
                    longest_match = entry

        if longest_match:
            return self.forward(packet, longest_match.gateway)

        return 'NO ROUTE'

    def match(self, network, mask, ip):
        return (ip & mask) == (network & mask)
```

### 路由器特点

| 特性 | 说明 |
|------|------|
| **工作层** | 网络层（L3） |
| **转发依据** | IP 地址 |
| **广播域** | 每个接口独立广播域 |
| **路由协议** | OSPF/BGP/RIP |
| **延迟** | 较高（软件转发） |
| **使用场景** | 连接不同网络的设备 |

## 对比

| 对比项 | 交换机 | 路由器 |
|--------|--------|--------|
| **工作层** | 数据链路层 | 网络层 |
| **转发依据** | MAC 地址 | IP 地址 |
| **广播域** | 共享广播域 | 隔离广播域 |
| **延迟** | 低 | 较高 |
| **功能** | 扩展局域网 | 网络互联 |
| **NAT** | 不支持 | 支持 |
| **ACL** | 有限 | 支持完整 ACL |
| **典型端口** | 24/48 口 | 4/8 口 |

## 三层交换机

将路由器和交换机的功能结合：

```python
# 三层交换机工作模式

class Layer3Switch:
    def __init__(self):
        self.switch_table = {}  # MAC -> Port
        self.router_table = {}   # IP -> Next Hop

    def process_frame(self, frame):
        if self.is_ip_frame(frame):
            return self.route_packet(frame)
        else:
            return self.switch_frame(frame)

    def switch_frame(self, frame):
        dst_mac = frame.destination_mac

        if dst_mac in self.switch_table:
            port = self.switch_table[dst_mac]
            self.send(port, frame)
        else:
            self.flood(frame)

    def route_packet(self, packet):
        dst_ip = packet.destination_ip

        if self.in_same_network(dst_ip):
            return self.switch_frame(self.create_frame(packet))
        else:
            next_hop = self.lookup_route(dst_ip)
            return self.send_to_gateway(next_hop, packet)
```

## 配置示例

### 交换机配置

```bash
# 创建 VLAN
vlan 10
name Sales

# 配置端口
interface FastEthernet0/1
switchport mode access
switchport access vlan 10

# 配置 trunk
interface FastEthernet0/24
switchport mode trunk
switchport trunk allowed vlan 10,20,30
```

### 路由器配置

```bash
# 配置接口
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

interface GigabitEthernet0/1
ip address 10.0.0.1 255.255.255.0
no shutdown

# 配置静态路由
ip route 0.0.0.0 0.0.0.0 10.0.0.254

# 配置 ACL
access-list 100 permit tcp any any eq 80
access-list 100 permit tcp any any eq 443
```

## 小结

- **交换机**：L2 设备，基于 MAC 转发，扩展局域网
- **路由器**：L3 设备，基于 IP 路由，连接不同网络
- **三层交换机**：结合两者功能，用于高性能网络
- **选择依据**：根据网络规模和需求选择合适设备
