## 概述

端口转发和端口映射是网络运维中的重要技术，用于将外部网络请求转发到内部服务，实现服务暴露和访问控制。

## 端口转发 vs 端口映射

| 对比项 | 端口转发 | 端口映射 |
|--------|----------|----------|
| **方向** | 双向 | 单向 |
| **转换** | 转换端口和地址 | 映射内外网端口 |
| **用途** | 穿透防火墙、安全隧道 | 服务暴露 |
| **协议** | TCP/UDP | TCP/UDP |

## iptables 端口转发

### 本地端口转发

```bash
# 转发本机 80 端口到 8080
iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080

# 转发到其他主机
iptables -t nat -A PREROUTING -p tcp --dport 80 -j DNAT --to-destination 192.168.1.100:8080
iptables -t nat -A POSTROUTING -j MASQUERADE

# 查看规则
iptables -t nat -L -n

# 删除规则
iptables -t nat -D PREROUTING 1
```

### 永久保存

```bash
# Debian/Ubuntu
apt install iptables-persistent
netfilter-persistent save

# CentOS/RHEL
service iptables save

# 使用 firewalld
firewall-cmd --add-forward-port=port=80:proto=tcp:toport=8080
firewall-cmd --runtime-to-permanent
```

### 规则示例

```bash
# 1. 将外部流量转发到内网主机
iptables -t nat -A PREROUTING -i eth0 -p tcp --dport 80 \
  -j DNAT --to-destination 192.168.1.100:8080

# 2. 允许转发
iptables -A FORWARD -i eth0 -o eth1 -p tcp --dport 8080 \
  -d 192.168.1.100 -j ACCEPT

# 3. SNAT 伪装
iptables -t nat -A POSTROUTING -o eth0 -j MASQUERADE
```

## socat 端口转发

### 安装

```bash
# Debian/Ubuntu
apt install socat

# CentOS
yum install socat

# macOS
brew install socat
```

### 基本使用

```bash
# 本地端口转发
socat TCP-LISTEN:8080,fork TCP:localhost:80

# 远程转发
socat TCP-LISTEN:80,fork TCP:192.168.1.100:80

# 保持持久
nohup socat TCP-LISTEN:8080,fork TCP:localhost:80 &

# 带日志
socat -d -d TCP-LISTEN:8080,crlf TCP:localhost:80
```

### 高级用法

```bash
# UDP 转发
socat UDP-LISTEN:53,fork UDP:8.8.8.8:53

# SSL 转发
socat OPENSSL-LISTEN:443,cert=cert.pem,key=key.pem TCP:localhost:80

# 地址重用
socat TCP-LISTEN:8080,reuseaddr,fork TCP:localhost:80

# 限制连接数
socat TCP-LISTEN:8080,fork,backlog=10 TCP:localhost:80

# 代理转发
socat TCP-LISTEN:8080 SOCKS:192.168.1.100:80,socksport=1080
```

## SSH 端口转发

### 本地端口转发

```bash
# 格式
ssh -L [本地 IP:]本地端口:目标主机:目标端口 用户@跳板机

# 示例：访问内网数据库
ssh -L 3306:192.168.1.100:3306 user@bastion.com

# 浏览器访问内网 web
ssh -L 8080:localhost:80 user@bastion.com

# 后台运行
ssh -f -N -L 3306:192.168.1.100:3306 user@bastion.com
```

### 远程端口转发

```bash
# 格式
ssh -R [远程 IP:]远程端口:目标主机:目标端口 用户@远程主机

# 示例：在服务器暴露本地服务
ssh -R 8080:localhost:3000 user@server.com

# 监听所有地址
ssh -R 0.0.0.0:8080:localhost:3000 user@server.com

# 需要 GatewayPorts yes
```

### 动态端口转发（SOCKS 代理）

```bash
# 创建 SOCKS 代理
ssh -D 1080 user@server.com

# 浏览器配置 SOCKS 代理
# SOCKS Host: localhost:1080

# 完整代理配置
ssh -f -N -D 1080 user@server.com

# 命令行使用代理
curl --socks5 localhost:1080 http://example.com
```

### SSH 隧道脚本

```bash
#!/bin/bash

# 创建 SSH 隧道的函数
create_tunnel() {
    local local_port=$1
    local remote_host=$2
    local remote_port=$3
    local jump_host=$4

    ssh -L ${local_port}:${remote_host}:${remote_port} -N -f ${jump_host}
}

# 创建多个隧道
create_tunnel 3306 192.168.1.100 3306 user@bastion.com
create_tunnel 6379 192.168.1.101 6379 user@bastion.com

# 检查隧道
ps aux | grep "ssh -L"

# 关闭隧道
pkill -f "ssh -L"
```

## Nginx 端口转发

```nginx
# TCP 端口转发
stream {
    upstream mysql {
        server 192.168.1.100:3306;
    }

    server {
        listen 3306;
        proxy_pass mysql;
        proxy_connect_timeout 60s;
    }

    upstream redis {
        server 192.168.1.101:6379;
    }

    server {
        listen 6379;
        proxy_pass redis;
    }
}
```

## Docker 端口映射

```bash
# 暴露单个端口
docker run -p 8080:80 nginx

# 暴露多个端口
docker run -p 8080:80 -p 443:443 nginx

# 绑定特定 IP
docker run -p 127.0.0.1:8080:80 nginx

# UDP 端口
docker run -p 53:53/udp dns-server

# 随机映射
docker run -P nginx
docker port container_name
```

### Docker Compose

```yaml
version: '3'
services:
  web:
    image: nginx
    ports:
      - "8080:80"
      - "443:443"

  db:
    image: mysql:5.7
    ports:
      - "3306:3306"
    environment:
      - MYSQL_ROOT_PASSWORD=secret

  redis:
    image: redis
    ports:
      - "6379:6379"
```

## Kubernetes 端口转发

```bash
# 转发到 pod
kubectl port-forward pod/my-pod 8080:80

# 转发到 service
kubectl port-forward svc/my-service 8080:80

# 转发到 deployment
kubectl port-forward deployment/my-deployment 8080:80

# 监听所有地址
kubectl port-forward --address 0.0.0.0 svc/my-service 8080:80
```

### YAML 配置

```yaml
apiVersion: v1
kind: Service
metadata:
  name: my-service
spec:
  type: NodePort
  selector:
    app: my-app
  ports:
    - protocol: TCP
      port: 80
      targetPort: 80
      nodePort: 30080
```

## 应用场景

### 场景一：内网穿透

```bash
# 通过公网服务器访问内网服务
# 在内网机器上执行
ssh -R 8080:localhost:3000 user@public.server.com

# 现在可以通过 public.server.com:8080 访问内网服务
```

### 场景二：数据库访问

```bash
# 临时访问远程数据库
ssh -L 3306:localhost:3306 user@db-server.com

# 本地 3306 端口连接到远程数据库
mysql -h localhost -u root -p
```

### 场景三：本地开发

```bash
# 暴露本地服务供外网测试
ssh -R 80:localhost:3000 user@server.com

# 配合 ngrok 使用
ngrok http 3000
```

## 安全注意事项

```bash
# 限制来源 IP
iptables -A INPUT -p tcp --dport 8080 -s 192.168.1.0/24 -j ACCEPT
iptables -A INPUT -p tcp --dport 8080 -j DROP

# 只允许特定用户
AllowUsers user@192.168.1.0/24

# 禁用密码登录（使用密钥）
PasswordAuthentication no

# 限制连接数
iptables -A INPUT -p tcp --dport 80 -m connlimit --connlimit-above 100 -j REJECT
```

## 常用命令汇总

```bash
# iptables 端口转发
iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080

# socat 端口转发
socat TCP-LISTEN:8080,fork TCP:localhost:80

# SSH 本地转发
ssh -L 8080:localhost:80 user@server.com

# SSH 远程转发
ssh -R 8080:localhost:80 user@server.com

# SSH 动态转发
ssh -D 1080 user@server.com

# Docker 端口映射
docker run -p 8080:80 nginx

# Kubernetes 端口转发
kubectl port-forward svc/my-svc 8080:80
```

## 小结

端口转发和端口映射要点：

- **iptables**：Linux 防火墙，功能强大
- **socat**：简单易用的端口转发工具
- **SSH**：安全的远程端口转发
- **Nginx**：支持 TCP 端口转发
- **安全优先**：限制来源 IP，禁止密码登录
