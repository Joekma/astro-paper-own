> 端口转发和映射实现服务访问。

## iptables 端口转发

```bash
# 端口转发
iptables -t nat -A PREROUTING -p tcp --dport 80 -j REDIRECT --to-port 8080
```

## socat 端口映射

```bash
# 端口映射
socat TCP-LISTEN:8080,fork TCP:127.0.0.1:80
```

## 小结

- **iptables**：Linux 防火墙
- **socat**：端口转发工具
- **端口映射**：内网服务暴露
