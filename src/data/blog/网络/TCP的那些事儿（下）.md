> TCP 流量控制和拥塞控制保证网络稳定。

## 滑动窗口

| 窗口类型 | 说明 |
|----------|------|
| **发送窗口** | 发送端缓冲区 |
| **接收窗口** | 接收端缓冲区 |

## 拥塞控制

| 算法 | 说明 |
|------|------|
| **慢启动** | 指数增长 |
| **拥塞避免** | 加法增长 |
| **快重传** | 3次重复确认 |
| **快恢复** | 快速恢复 |

## 小结

- **滑动窗口**：流量控制
- **拥塞控制**：避免网络拥塞
