> 性能测试衡量系统处理能力。

## 关键指标

| 指标 | 说明 |
|------|------|
| **QPS** | 每秒查询数 |
| **TPS** | 每秒事务数 |
| **并发量** | 同时处理的请求数 |
| **响应时间** | RT |
| **吞吐量** | 系统处理能力 |

## 计算公式

| 公式 | 说明 |
|------|------|
| QPS = 并发数 / 平均响应时间 |
| 并发数 = QPS * 响应时间 |

## 小结

- **QPS**：每秒查询数
- **并发**：同时连接数
- **响应时间**：处理速度
