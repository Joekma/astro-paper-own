## 概述

加密算法是保护数据安全的核心技术，主要分为**对称加密**和**非对称加密**两大类。

## 加密体系对比

| 特性 | 对称加密 | 非对称加密 |
|------|----------|------------|
| 密钥数量 | 一个（共享密钥） | 一对（公钥+私钥） |
| 加密速度 | 快 | 慢 |
| 适用场景 | 大数据加密 | 密钥交换、数字签名 |
| 密钥管理 | 困难（需安全传输） | 简单（公钥可公开） |

## 对称加密

### 加密原理

```
明文 + 密钥 → 密文
密文 + 密钥 → 明文
```

发送方和接收方使用**相同的密钥**进行加密和解密。

### 常见算法

| 算法 | 密钥长度 | 说明 |
|------|----------|------|
| **DES** | 56位 | 已淘汰，存在安全漏洞 |
| **3DES** | 168位 | DES 的改进版，效率低 |
| **AES** | 128/192/256位 | 当前标准，最常用 |
| **RC4** | 可变 | 流加密，已不安全 |
| **ChaCha20** | 256位 | 高性能，现代化算法 |

### AES 详解

AES（Advanced Encryption Standard）是目前最流行的对称加密算法：

```python
from Crypto.Cipher import AES
from Crypto.Random import get_random_bytes

# 生成密钥
key = get_random_bytes(16)  # 128位

# 加密
cipher = AES.new(key, AES.MODE_GCM)
ciphertext, tag = cipher.encrypt_and_digest(data)

# 解密
cipher = AES.new(key, AES.MODE_GCM, nonce=nonce)
plaintext = cipher.decrypt_and_verify(ciphertext, tag)
```

### 工作模式

| 模式 | 说明 | 特点 |
|------|------|------|
| **ECB** | 电子密码本 | 相同明文产生相同密文，不安全 |
| **CBC** | 密码块链接 | 需初始向量，串行处理 |
| **CTR** | 计数器模式 | 可并行，加密解密独立 |
| **GCM** | 伽罗瓦计数器模式 | 支持认证，推荐使用 |

### CBC 模式示例

```python
from Crypto.Cipher import AES
from Crypto.Util.Padding import pad, unpad

def aes_cbc_encrypt(data, key, iv):
    cipher = AES.new(key, AES.MODE_CBC, iv)
    padded_data = pad(data, AES.block_size)
    return cipher.encrypt(padded_data)

def aes_cbc_decrypt(ciphertext, key, iv):
    cipher = AES.new(key, AES.MODE_CBC, iv)
    padded_data = cipher.decrypt(ciphertext)
    return unpad(padded_data, AES.block_size)
```

## 非对称加密

### 加密原理

```
明文 + 公钥 → 密文
密文 + 私钥 → 明文
```

发送方使用接收方的**公钥**加密，接收方使用**私钥**解密。

### 常见算法

| 算法 | 密钥长度 | 说明 |
|------|----------|------|
| **RSA** | 2048/4096位 | 最通用，用于加密和签名 |
| **DSA** | 1024-3072位 | 仅用于数字签名 |
| **ECC** | 256/384/512位 | 高效率，移动端推荐 |
| **DH** | 可变 | 密钥交换协议 |
| **ElGamal** | 可变 | 基于离散对数 |

### RSA 示例

```python
from Crypto.PublicKey import RSA
from Crypto.Cipher import PKCS1_OAEP
from Crypto.Signature import pkcs1_15
from Crypto.Hash import SHA256

# 生成密钥对
key = RSA.generate(2048)
private_key = key.export_key()
public_key = key.publickey().export_key()

# 加密
cipher = PKCS1_OAEP.new(RSA.import_key(public_key))
ciphertext = cipher.encrypt(message)

# 解密
cipher = PKCS1_OAEP.new(RSA.import_key(private_key))
message = cipher.decrypt(ciphertext)

# 签名
signer = pkcs1_15.new(RSA.import_key(private_key))
signature = signer.sign(SHA256.new(data))

# 验证
verifier = pkcs1_15.new(RSA.import_key(public_key))
try:
    verifier.verify(SHA256.new(data), signature)
    print("签名有效")
except ValueError:
    print("签名无效")
```

### ECC 椭圆曲线加密

ECC 使用更短的密钥达到相同安全级别：

| RSA 位数 | ECC 位数 | 安全等级 |
|----------|----------|----------|
| 2048 | 224 | 相当 |
| 3072 | 256 | 相当 |
| 7680 | 384 | 相当 |
| 15360 | 512 | 相当 |

```python
from Crypto.PublicKey import ECC

# 生成 ECC 密钥
key = ECC.generate(curve='P-256')
private_key = key.export_key(format='PEM')
public_key = key.publickey().export_key(format='PEM')
```

## 混合加密体系

实际应用中，通常结合对称和非对称加密：

### 加密流程

```
发送方：
1. 生成会话密钥（对称加密密钥）
2. 用公钥加密会话密钥
3. 用会话密钥加密数据
4. 发送：加密的会话密钥 + 加密的数据

接收方：
1. 用私钥解密会话密钥
2. 用会话密钥解密数据
```

### Python 实现

```python
import rsa
from Crypto.Cipher import AES, PKCS1_OAEP
from Crypto.Random import get_random_bytes

# 发送方
def encrypt_message(message, public_key):
    # 生成会话密钥
    session_key = get_random_bytes(32)

    # 用公钥加密会话密钥
    cipher_rsa = PKCS1_OAEP.new(rsa.PublicKey.load_pkcs1(public_key))
    encrypted_key = cipher_rsa.encrypt(session_key)

    # 用会话密钥加密数据
    cipher_aes = AES.new(session_key, AES.MODE_GCM)
    ciphertext, tag = cipher_aes.encrypt_and_digest(message)

    return encrypted_key + tag + ciphertext

# 接收方
def decrypt_message(encrypted_data, private_key):
    # 分离各部分
    encrypted_key = encrypted_data[:256]
    tag = encrypted_data[256:272]
    ciphertext = encrypted_data[272:]

    # 用私钥解密会话密钥
    cipher_rsa = PKCS1_OAEP.new(rsa.PrivateKey.load_pkcs1(private_key))
    session_key = cipher_rsa.decrypt(encrypted_key)

    # 用会话密钥解密数据
    cipher_aes = AES.new(session_key, AES.MODE_GCM)
    return cipher_aes.decrypt_and_verify(ciphertext, tag)
```

## 数字签名

数字签名用于验证消息来源和完整性：

```python
from Crypto.Signature import pkcs1_15
from Crypto.Hash import SHA256

# 签名
def sign_data(data, private_key):
    h = SHA256.new(data)
    signature = pkcs1_15.new(rsa.PrivateKey.load_pkcs1(private_key)).sign(h)
    return signature

# 验证
def verify_signature(data, signature, public_key):
    h = SHA256.new(data)
    try:
        pkcs1_15.new(rsa.PublicKey.load_pkcs1(public_key)).verify(h, signature)
        return True
    except ValueError:
        return False
```

## 应用场景

| 场景 | 加密方案 |
|------|----------|
| HTTPS | 混合加密（RSA+AES） |
| 文件加密 | AES 对称加密 |
| 数字证书 | 非对称加密签名 |
| 区块链 | 椭圆曲线签名 |
| SSH/SSL | 混合加密体系 |
| VPN | 混合加密通道 |

## 安全建议

1. **使用强密钥**：AES-256 或 RSA-2048 以上
2. **避免 ECB 模式**：使用 CBC/GCM 等安全模式
3. **使用标准库**：避免自己实现加密算法
4. **保护私钥**：私钥泄露则加密无效
5. **定期轮换密钥**：降低密钥泄露风险
6. **验证签名**：确保数据来源可信

## 小结

- **对称加密**：速度快，适合大量数据，用 AES-256-GCM
- **非对称加密**：密钥安全，适合密钥交换，用 RSA-2048 或 ECC
- **混合加密**：结合两者优点，实际应用的主流方案
- **数字签名**：验证来源和完整性，防篡改
