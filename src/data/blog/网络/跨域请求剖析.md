> 跨域请求需要特殊处理。

## 同源策略

| 同源条件 | 说明 |
|---------|------|
| 协议相同 | http/https |
| 域名相同 | example.com |
| 端口相同 | 8080 |

## 解决方案

| 方案 | 说明 |
|------|------|
| JSONP | 仅支持 GET |
| CORS | 推荐方案 |
| 代理服务器 | Nginx/Node |
| postMessage | 页面间通信 |

## 小结

- **同源策略**：浏览器安全限制
- **CORS**：服务端配置
- **JSONP**：早期兼容方案
