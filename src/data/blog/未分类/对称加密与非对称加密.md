> 加密算法保护数据安全。

## 对称加密

| 算法 | 说明 |
|------|------|
| **AES** | 高级加密标准 |
| **DES** | 数据加密标准 |
| **3DES** | 三重DES |

## 非对称加密

| 算法 | 说明 |
|------|------|
| **RSA** | 公钥私钥 |
| **DSA** | 数字签名 |

## 小结

- **对称加密**：AES/DES
- **非对称加密**：RSA/ DSA
