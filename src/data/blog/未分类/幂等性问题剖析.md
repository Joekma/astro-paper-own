> 幂等性保障接口安全重试。

## 幂等性定义

| 方法 | 说明 |
|------|------|
| **GET** | 幂等 |
| **PUT** | 幂等 |
| **DELETE** | 幂等 |

## 实现方案

```python
# Token 方案
token = redis.get('token')
if token:
    return '重复请求'

redis.setex('token', 'used', 60)
```

## 小结

- **幂等性**：接口设计重要原则
- **Token**：防重复提交
