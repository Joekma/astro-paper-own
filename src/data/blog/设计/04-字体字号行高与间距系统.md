## 核心结论

很多页面显得粗糙，不是因为颜色不够炫，而是字体、字号、行高和间距没有体系。排版是页面设计最稳定的底盘。

优秀界面通常只使用有限的字号层级，但每一级都有明确用途。标题、正文、辅助说明、标签、按钮、数字和表格字段应该各司其职。

## 字体选择

中文业务系统建议优先使用系统字体栈，稳定、清晰、性能好：

```css
font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI",
  "PingFang SC", "Microsoft YaHei", sans-serif;
```

数据型系统可以启用等宽数字，让金额、比例、时间更容易纵向比较：

```css
font-variant-numeric: tabular-nums;
```

## 字号层级

建议先定义 6 个层级：

- 页面标题：20-24px。
- 区块标题：16-18px。
- 正文：14-16px。
- 辅助文字：12-13px。
- 标签文字：12px。
- 大屏或官网标题：28-40px。

不要在同一个页面里混用太多接近的字号，例如 13、14、15、16 随机出现。它会让页面像临时拼接。

## 间距系统

推荐使用 8px 间距体系：

- 4px：图标和文字之间。
- 8px：小组件内部。
- 12px：紧凑列表。
- 16px：常规组件间距。
- 24px：分组间距。
- 32px：页面区块间距。
- 48px：大区块或展示页间距。

高级感来自关系稳定。同样的关系用同样间距，不同层级用明显不同的间距。

## AI 开发提示词

```text
请为【页面名称】建立排版和间距规范。
要求给出页面标题、区块标题、正文、辅助文字、标签、按钮的字号、行高、字重和使用场景。
间距使用 4/8/12/16/24/32/48，不要随机写孤立值。
```

## 检查清单

- 页面是否只有有限字号层级？
- 标题和正文行高是否舒适？
- 同级模块间距是否一致？
- 表格数字是否便于比较？
- 移动端按钮和输入框是否容易触控？
