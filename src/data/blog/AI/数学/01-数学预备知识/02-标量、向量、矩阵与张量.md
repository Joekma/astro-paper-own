## 四个名称描述的是数据结构

标量、向量、矩阵和张量首先回答的不是“数据有什么业务含义”，而是“需要多少个索引才能定位一个元素”。

| 对象 | 记号          | 示例 Shape | 定位元素            |
| ---- | ------------- | ---------- | ------------------- |
| 标量 | $a$           | `[]`       | 不需要索引          |
| 向量 | $\mathbf{x}$  | `[D]`      | $x_i$               |
| 矩阵 | $\mathbf{X}$  | `[M,N]`    | $X_{ij}$            |
| 张量 | $\mathcal{X}$ | `[B,T,C]`  | $\mathcal{X}_{btc}$ |

标量是一个数，例如学习率 $\eta=0.001$。向量是一列有顺序的数，例如某个 Token 的 $D$ 维表示。矩阵有两个轴，例如词表中全部 Token 的 Embedding 表。机器学习语境中的“张量”通常泛指具有任意个轴的数值数组，矩阵和向量也可以看成低阶张量。

数学里“张量”还有更严格的坐标变换定义。本系列讨论工程计算时，除非特别说明，采用深度学习框架中的数组含义。

## 轴数、Shape 与元素总数

轴数也叫维数或 rank，但“维数”容易产生歧义：向量 $\mathbf{x}\in\mathbb{R}^{768}$ 是一阶对象，却含有 768 个分量。因此更清楚的说法是：

- 它有 1 个轴；
- Shape 是 `[768]`；
- 这个轴的长度是 768。

若 $\mathcal{X}$ 的 Shape 为 `[B,T,C]`，元素总数为：

$$
|\mathcal{X}|=B\times T\times C
$$

例如 `[2,3,4]` 表示 2 个样本、每个样本 3 个位置、每个位置 4 个特征，共有 $2\times3\times4=24$ 个数。`X[1,2,0]` 只在知道三个轴分别代表什么后才有意义。

Shape 相同不代表语义相同。`[32,128]` 既可能表示 32 个样本的 128 维特征，也可能表示一张灰度图。工程中应同时记录 Shape、数据类型和轴语义。

## 从 Token ID 到表示张量

设批次大小为 $B$，序列长度为 $T$，词表大小为 $V$，特征维度为 $C$：

- Token ID 的 Shape 是 `[B,T]`，每个元素是 $0$ 到 $V-1$ 的整数；
- Embedding 表 $\mathbf{E}$ 的 Shape 是 `[V,C]`；
- 查表后的表示 $\mathcal{X}$ 的 Shape 是 `[B,T,C]`。

对第 $b$ 个样本、第 $t$ 个位置：

$$
\mathcal{X}_{btc}=E_{\,I_{bt},c}
$$

$I_{bt}$ 是 Token ID，它选择 Embedding 表的一行；$c$ 遍历该行的特征。这个过程把离散索引变成连续向量，但没有改变批次和序列两个轴。

## Shape 变化必须有理由

常见操作可以按轴理解：

- `reshape` 重新解释轴，但要求元素总数不变；
- `transpose` 交换轴的顺序；
- `concat` 沿某个轴拼接，只有该轴长度相加；
- `sum` 或 `mean` 沿指定轴聚合，通常会移除或压缩该轴；
- broadcasting 在兼容的长度为 1 的轴上复用数据。

例如对 `[B,T,C]` 沿 `T` 求平均，得到 `[B,C]`。这表示每个样本的所有位置被聚合为一个向量。若误沿 `C` 求平均，则得到 `[B,T]`，数学上能运行，语义却完全不同。

## 常见误区

- 把“张量”理解成一定比矩阵复杂；它只是允许更多轴。
- 只检查元素总数，不检查每个轴的含义。
- 把 Token ID 当作连续数值；ID 是索引，大小通常没有语义。
- 认为 reshape 会自动保留业务语义；它只保证元素数量不变。
- 混用“轴数”和“轴长度”，导致“768 维向量是 768 阶张量”之类错误。

## 本篇自检

1. `[4,10,64]` 有几个轴、多少个元素？
2. `[B,T,C]` 沿 `T` 求和后通常得到什么 Shape？
3. 两个张量 Shape 相同，为什么仍不能断定可以互换？

<details>
<summary>查看答案</summary>

1. 有 3 个轴，共 $4\times10\times64=2560$ 个元素。
2. 若不保留被聚合轴，结果为 `[B,C]`。
3. 它们的数据类型、单位和轴语义可能不同。

</details>

## 小结

标量、向量、矩阵和张量的区别在于轴的数量；真正决定数据能否正确计算的，是 Shape 与每个轴的语义。下一篇讨论函数如何把一种对象映射成另一种对象。
