> 爬虫是获取互联网数据的重要手段。本文详细介绍爬虫的定义、流程和相关概念。

## 爬虫概述

### 什么是爬虫

**爬虫的定义**：向网站发起请求，获取资源后分析并提取有用数据的程序。

> 如果把互联网比作一张大的蜘蛛网，那一台计算机上的数据便是蜘蛛网上的一个猎物，而爬虫程序就是一只小蜘蛛，沿着蜘蛛网抓取自己想要的猎物/数据。

### 爬虫的价值

- 天猫商城的商品信息
- 链家网的租房信息
- 雪球网的证券投资信息

> 谁掌握了行业内的第一手数据，谁就成了整个行业的主宰。

## 爬虫基本流程

1. **发起请求**：使用 `requests` 库向目标站点发起请求（Request）
2. **获取响应内容**：服务器返回 Response（html，json，图片，视频等）
3. **解析内容**：
   - 解析 html：正则表达式、BeautifulSoup、pyquery
   - 解析 json：`json` 模块
   - 解析二进制数据：以 `b` 方式写入文件
4. **保存数据**：数据库、文件

## 请求与响应

| 概念 | 说明 |
|------|------|
| **Request** | 用户通过浏览器（socket client）发送给服务器（socket server） |
| **Response** | 服务器返回的数据，可能包含其他资源链接 |

> 浏览器在接收 Response 后会解析显示给用户，而爬虫只提取有用数据。

## Request

### 请求方式

| 方式 | 说明 |
|------|------|
| **GET** | 默认方式，数据在 URL 中 |
| **POST** | 数据在请求体中，适合登录等场景 |
| HEAD/PUT/DELETE/OPTIONS | 其他请求方式 |

### 请求 URL

**URL全称统一资源定位符**，用于唯一确定一个资源（网页、图片、视频等）。

### 请求头

- **User-agent**：客户端标识，务必添加
- **Host**：主机地址
- **Cookies**：保存登录信息
- **Referer**：上一次的跳转路径

### 请求体

- GET 方式：请求体为空
- POST 方式：请求体是 form data

### 示例代码

```python
import requests
from urllib.parse import urlencode

# 带参数请求
keywords = "python"
response = requests.get(
    "https://www.baidu.com/s",
    params={"wd": keywords, "pn": 20},
    headers={
        "User-Agent": "Mozilla/5.0 (Windows NT 6.1; Win64; x64) AppleWebKit/537.36"
    }
)

# 保存响应
with open("result.html", "w", encoding="utf-8") as f:
    f.write(response.text)
```

## Response

### 响应状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 301 | 跳转 |
| 404 | 文件不存在 |
| 403 | 权限不足 |
| 502 | 服务器错误 |

### Response Header

- **Location**：跳转地址
- **Set-Cookie**：保存 cookie 信息

### 常用框架

**Scrapy** 是最流行的 Python 爬虫框架。

```python
# Scrapy 基本使用
import scrapy

class MySpider(scrapy.Spider):
    name = 'myspider'

    def start_requests(self):
        urls = ['http://example.com']
        for url in urls:
            yield scrapy.Request(url, self.parse)

    def parse(self, response):
        # 提取数据
        for item in response.css('div.item'):
            yield {
                'title': item.css('title::text').get(),
                'link': item.css('a::attr(href)').get()
            }
```

## 小结

**爬虫流程**：爬取 → 解析 → 存储

**核心要点**：
- 模拟浏览器发送请求
- 提取有用数据
- 遵守网站 robots.txt 协议
