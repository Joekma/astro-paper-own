> 分布式事务是分布式系统的难点。

## CAP 定理

| 特性 | 说明 |
|------|------|
| **Consistency** | 一致性 |
| **Availability** | 可用性 |
| **Partition** | 分区容错 |

## BASE 理论

| 特性 | 说明 |
|------|------|
| **Basically Available** | 基本可用 |
| **Soft state** | 软状态 |
| **Eventually consistent** | 最终一致 |

## 小结

- **CAP**：三选二
- **BASE**：妥协方案
